Single-Call Example App

The simplest agentic building block: one prompt goes in, one model response comes out — no retrieval, no external tools, no multi-step chaining. Toggle between a plain-text response and a schema-conforming structured response to see the same pattern rendered both ways.

What is the single-call pattern?

A single call sends one prompt to the shared generation service and returns one response, with nothing in between — no dataset lookup, no external tool, no follow-up call. It's the right choice for straightforward tasks like summarizing, classifying, or extracting information from a piece of text, where grounding in outside data or live information isn't required.

Embeddings Example App

Every piece of text below has been converted into a numeric vector by the shared embedding model, then projected into 2D so semantically similar texts land near each other. Add your own word or phrase to see where it falls among them.

What is an embedding?

An embedding is a numeric vector produced by a model such that texts with similar meaning end up with similar vectors. BWS4 uses one shared embedding model across every example app — the same model that scores passages in the RAG app is used here to place text in space, so "joy" lands near "excitement" and far from "database."
